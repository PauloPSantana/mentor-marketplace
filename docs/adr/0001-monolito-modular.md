# ADR 0001 — Monólito Modular

## Status
Aceito.

## Contexto
O produto está em fase de MVP e ainda precisa validar mercado.

## Decisão
Usar monólito modular em vez de microsserviços.

## Consequências positivas
- menor custo operacional;
- deploy simples;
- transações mais simples;
- desenvolvimento mais rápido;
- fronteiras de domínio preservadas.

## Evolução futura
Módulos com maior necessidade de escala poderão ser extraídos posteriormente.
